# CMA — headline font

Inter Tight variable, upright, weight range 100–900. Headlines use weight 700; body text remains Inter, wishes remain Lora italic.

Source: https://github.com/google/fonts/tree/main/ofl/intertight
Downloaded original: https://raw.githubusercontent.com/google/fonts/main/ofl/intertight/InterTight%5Bwght%5D.ttf
Local file: dist/assets/inter-tight-variable.ttf
License: SIL Open Font License 1.1, retained at dist/assets/inter-tight-OFL.txt

The source font is unmodified. Cyrillic glyph coverage and headline line widths were checked against the font's actual metrics. The font is hosted with the Site; the visitor does not request it from Google.
